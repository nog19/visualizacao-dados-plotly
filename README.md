# Projeto — Visualização de Dados com Plotly

Neste projeto aprendi a gerar gráficos a partir de uma base de dados (fornecida pelo curso). Utilizei o Plotly para criar gráficos interativos e eficientes, explorando diferentes tipos de visualizações e recursos interativos (hover, zoom, seleção, etc.).

## O que tem aqui
- Scripts em Python que carregam e tratam os dados.
- Exemplos de gráficos interativos usando Plotly (scatter, line, bar, histograma, heatmap, etc.).
- Notebooks (se houver) com análises e explicações passo a passo.

## Requisitos
- Python 3.8+
- Bibliotecas principais:
  - plotly
  - pandas
  - numpy (opcional, dependendo dos scripts)

Instalação rápida:
```bash
pip install plotly pandas numpy
```
ou, se houver um arquivo requirements.txt:
```bash
pip install -r requirements.txt
```

## Como usar
1. Coloque a base de dados na pasta indicada pelo script (ex: `data/`) ou ajuste o caminho no código.
2. Execute o script ou notebook:
```bash
python src/gerar_graficos.py
# ou
jupyter notebook notebooks/analise.ipynb
```
3. Os gráficos interativos serão abertos no navegador ou salvos em arquivos HTML, dependendo do script.

## Observações
- O projeto serve principalmente como exercício para aprender Plotly e técnicas básicas de visualização e pré-processamento de dados.
- Ajuste os scripts conforme a estrutura da sua base de dados.
